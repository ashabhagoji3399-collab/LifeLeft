Job & Internship Tracker

A simple and responsive web application to track job and internship applications in one place.

Features

- Add job and internship applications
- Track application status
- Dashboard with application statistics
- Applied, Interview, Selected and Rejected status
- Delete applications
- Data persists after browser refresh using Local Storage
- Responsive design for desktop and mobile

Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

How to Use

1. Enter the company name.
2. Enter the job or internship role.
3. Select the application date.
4. Choose the application status.
5. Click Add Application.
6. View your applications and dashboard statistics.
